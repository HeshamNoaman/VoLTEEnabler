## 🎯 المشكلة والحل المبتكر

### حظر سامسونج في واجهة One UI
في هواتف سامسونج جالاكسي الحديثة التي تعمل بنظام أندرويد 13 و 14 (واجهة One UI 5 و 6)، قامت سامسونج بإلغاء تصدير واجهة إعدادات IMS المخفية (`com.samsung.advp.imssettings/.MainActivity`) وجعلها غير عامة (`android:exported="false"`). محاولة فتح هذه الواجهة مباشرة عبر التطبيقات أو عبر أوامر ADB العادية تفشل بالخطأ الأمني:
```text
java.lang.SecurityException: Permission Denial: starting Intent { cmp=com.samsung.advp.imssettings/.MainActivity } not exported from uid 10146
```

### التجاوز البرمجي الآمن بدون روت
يقوم تطبيق **مفعل VoLTE** بحل هذه المشكلة على الهاتف مباشرة باستخدام موفري إعدادات أندرويد وصلاحيات **شيزوكو (UID 2000)**:
1. **الطريقة الأولى: اختصار شاشة القفل (تعمل بنجاح 100% على أندرويد 10–15 بدون شيزوكو!)**:
   - تعيين الاختصار السفلي الأيمن لشاشة القفل مؤقتاً لفتح إعدادات IMS (`com.samsung.advp.imssettings/.MainActivity`) داخل جدول `Settings.System`.
   - يقوم نظام واجهة المستخدم لسامسونج (`SystemUI`) بتشغيل الواجهة المخفية بصلاحيات النظام المرتفعة فور سحب الأيقونة بعد إلغاء القفل.
   - تعمل باستخدام إذن أندرويد القياسي لتعديل الإعدادات (لا تحتاج روت ولا شيزوكو ولا كمبيوتر!).
   - بمجرد الدخول، تفعيل خيار **GCF MODE** يسجل الهاتف في شبكة VoLTE فوراً مع أي مشغل شبكة.
   - يتوفر زر استعادة فوري لإعادة اختصار الكاميرا الافتراضي بضغطة واحدة.
2. **الطريقة الثانية: المفتاح الجانبي / الضغط المزدوج على زر البور (أندرويد 10–12 فقط)**:
   - إعادة تعيين وظيفة الضغط مرتين على زر التشغيل (`function_key_config_doublepress_value`) لفتح إعدادات IMS على أندرويد 10 إلى 12.
   - *ملاحظة: في أندرويد 13 و 14 (One UI 5 و 6)، حظرت سامسونج هذه الطريقة برمجياً عبر كلاس `AdbCommandUtils` واشترطت وجود أيقونة لانشر في كلاس `KeyCustomizationInfoManager`.*
3. **الطريقة الثالثة: المساعد الرقمي (تعمل 100% على أندرويد 10–14 عبر شيزوكو)**:
   - تعيين إعدادات IMS كمساعد رقمي للنظام (`Settings.Secure.assistant`).
   - إرسال رمز المفتاح البرمجي `KEYCODE_ASSIST` (219) أو الضغط المطول على زر الشاشة الرئيسية لتفتح واجهة IMS فوراً.
   - يتوفر زر استعادة فوري لإعادة مساعد جوجل الافتراضي.
4. **الطريقة الرابعة: إصلاح وإعادة تفعيل حزم IMS بضغطة زر**:
   - فحص وتثبيت وتفعيل حزم سامسونج الأساسية لـ VoLTE في حال كانت معطلة أو محذوفة من المشغل (`com.sec.ims`, `com.sec.imsservice`, `com.samsung.advp.imssettings`, `com.sec.imslogger`, `com.sec.epdg`).

## ⚡ ميزات إضافية مدمجة

- **أدوات الشبكة والقوائم السرية**:
  - فتح واجهة اختبار الهاتف ومعلومات الشبكة **RadioInfo (`*#*#4636#*#*`)** لتفعيل خيارات *VoLTE الموردة*، ومكالمات الواي فاي، وتحديد نمط الشبكة المفضل (NR/LTE/GSM).
  - فتح إعدادات **نقاط الوصول (APN)** مباشرة (محدث لأندرويد 14 لتمرير معرف الشريحة النشطة `sub_id` تلقائياً لمنع إغلاق الشاشة).
  - زر بضغطة واحدة لاستعادة مربع تفعيل بيانات الهاتف المفقود من الإعدادات السريعة (`sysui_qs_tiles`).
  - اختصارات لوضع المهندس في معالجات ميدياتك (MTK EngineerMode)، واختيار الترددات، وإعدادات شبكة إل جي.
  - قائمة إعادة تشغيل الهاتف المتقدمة (تشغيل عادي، وضع الريكفري، وضع التنزيل/أودين، وضع البوتلودر).
- **ملفات إعدادات نقاط الوصول (APN) المسبقة**:
  - ملفات معدة وجاهزة للنسخ بضغطة زر:
    - **بيانات يمن موبايل 4G** (`ymdata`)
    - **مكالمات VoLTE يمن موبايل** (`ims`)
    - **خدمات VoLTE XCAP الإضافية** (`xcap`)
    - **إعدادات VoLTE العامة العالمية** (`ims`)
- **طرفية أوامر ADB تفاعلية مدمجة**:
  - موجه أوامر داخلي متكامل ينفذ أوامر الشيل المرتفعة فوراً مع عرض كود الخروج والمخرجات المباشرة.
  - أوامر تشخيصية سريعة بنقرة واحدة (`getprop ro.product.model`, `getprop gsm.sim.state`).
- **واجهة ثنائية اللغة ودعم كامل للغة العربية (RTL)**:
  - تعريب دقيق وطبيعي بالكامل مع مراعاة اتجاه النصوص من اليمين إلى اليسار.
  - زر تبديل اللغة بلمسة واحدة في الشريط العلوي.

## 📋 المتطلبات

1. **جهاز أندرويد**: نظام أندرويد 10.0 إلى أندرويد 14+ (يوصى بأجهزة سامسونج جالاكسي بواجهة One UI 2.0 إلى 6.1+).
2. **تطبيق شيزوكو (Shizuku)**: مثبت ويعمل على الهاتف.
   - [تحميل شيزوكو من GitHub](https://github.com/RikkaApps/Shizuku/releases) أو من متجر جوجل بلاي.
   - تشغيل شيزوكو عبر **تصحيح الأخطاء اللاسلكي (Wireless Debugging)** بدون كمبيوتر أو عبر أمر ADB لمرة واحدة.
   - منح الإذن لتطبيق **مفعل VoLTE** داخل تطبيق شيزوكو.

## 📥 التحميل والتثبيت

### الخيار 1: التحميل المباشر (موصى به)
حمل أحدث ملف APK جاهز للتثبيت مباشرة من قسم **[الإصدارات (Releases)](https://github.com/HeshamNoaman/VoLTEEnabler/releases)** وقم بتثبيته فوراً على هاتفك.

### الخيار 2: البناء من المصدر عبر ADB (للمطورين)
```bash
# 1. تجميع ملف APK
./gradlew assembleDebug

# 2. تثبيت التطبيق على الهاتف المتصل عبر ADB
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 🔒 الأمان والخصوصية

- **لا يتطلب روت**: تتم جميع العمليات المرتفعة عبر واجهة شيزوكو الآمنة (UID 2000).
- **عمليات آمنة وغير تخريبية**: تحتفظ جميع الطرق بنسخة احتياطية من إعداداتك السابقة وتوفر زراً للاستعادة بضغطة واحدة.
- **بدون أي إذن إنترنت**: يعمل التطبيق محلياً دون أي اتصال بالإنترنت أو إرسال أي بيانات خارجية مطلقاً.
